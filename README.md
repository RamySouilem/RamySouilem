### 👨‍💻 About Me

I'm a full-stack software engineer based in Sousse, Tunisia 🇹🇳, working remotely as an Application Developer at **Harvest Group** since 2023.

I started out in UX/UI design, then moved deeper into code. That background still shapes how I work: I care about clean interfaces, small details, and building things that actually make sense for the people using them.

Right now, my main stack is *React, TypeScript, C#, ASP.NET Core, PostgreSQL, Docker, and GitHub Actions*. I work across the frontend and backend, from UI work and API integration to database logic, debugging, testing, and CI/CD pipelines.

What I enjoy most is solving real client problems. Sometimes that means building a feature from scratch, sometimes it means fixing a painful bug, improving a workflow, cleaning up a messy implementation, or learning whatever technology is needed to get the job done properly.

- 🧩 I like turning unclear requirements into practical, working software.
- 🛠️ I’m comfortable jumping into unfamiliar codebases, debugging issues, and figuring things out.
- 🎨 My UX/UI background helps me think about usability before writing code.
- 🚀 I like owning the whole path: from the first commit to a container running in production.
